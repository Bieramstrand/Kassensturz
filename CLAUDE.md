# Hinweise für Claude

* Bei jeder Änderung an `index.html` die Version unten in der App hochzählen:
  `APP_VERSION` und `APP_DATE` (Format JJJJ-MM-TT, heutiges Datum) im Abschnitt
  „Version: bei jeder Änderung hier hochzählen“. Neue Funktion: mittlere Zahl
  erhöhen (2.16.0 → 2.17.0), reine Fehlerkorrektur: letzte Zahl (2.16.0 → 2.16.1).
* Halbe Halbe ist eine eigene App (Repo `Bieramstrand/halbehalbe`). Geteilte
  Einnahmen werden dort als Ausgabe mit negativem Betrag gespeichert.
* Texte für den Nutzer auf Deutsch und ohne Bindestriche.
